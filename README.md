# Теория — тренажёр сольфеджио, теории музыки и музлитературы

Android-приложение на Kotlin + Jetpack Compose (Material 3), полностью офлайн.
Собрано и протестировано в GitHub Actions; готовый debug APK — в артефактах workflow
`teoria-debug-apk`.

- minSdk 26, target/compileSdk 35, Kotlin 1.9.24, Compose BOM 2024.09.03, AGP 8.7.2, Gradle 8.9
- Room (topics / attempts / srs / profile), Navigation-Compose, SharedPreferences для инструмента
- Разрешения: только `POST_NOTIFICATIONS` (объявлено; уведомления не отправляются). Сеть не используется
- Звук синтезируется на устройстве через `AudioTrack` (синусоида с огибающей), внешних аудиофайлов нет

## Контент — данные, а не код

Весь учебный материал лежит в `app/src/main/assets/content/` и читается при старте;
Kotlin только разбирает JSON и параметрически генерирует задания.

| Файл | Что внутри | Объём |
|---|---|---|
| `theory.json` | 12 разделов теории, конспект каждой темы | **12 разделов / 126 тем** |
| `solfege.json` | 9 разделов сольфеджио | **9 разделов / 63 темы** |
| `literature.json` | 13 разделов музлитературы + карточки «композитор — эпоха — произведение» | **13 разделов / 87 тем / 244 карточки** |
| `generators.json` | тональности, интервалы, аккорды, размеры, темпы | **30 тональностей, 21 интервал, 4 трезвучия + 7 септаккордов, 8 размеров** |
| `themes.json` | нотные инципиты для прослушивания и игры | **32 темы / 21 композитор** |

### Разделы теории (126 тем)

1. Звук и его свойства (высота, обертоны, диапазоны голосов и инструментов)
2. Нотация (октавы, ключи скрипичный/басовый/альтовый/теноровый, добавочные линии, альтерация, буквенные обозначения)
3. Ритм и метр (длительности до 64-х, точка, лига, триоли/дуоли, 2/4 3/4 4/4 6/8 9/8 12/8 5/4 7/8, синкопа, темпы, артикуляция)
4. Лад и тональность (мажор и минор трёх видов, все 30 тональностей, квинтовый круг, энгармонизм, параллельные/одноимённые, лады народной музыки)
5. Интервалы (14 простых, составные 9–14, обращения, энгармонизм, ув2/ум7, тритоны, консонансы)
6. Аккорды (4 вида трезвучий и обращения, 7 видов септаккордов, D7/D65/D43/D2, вводные, SII7, функции T S D)
7. Гармония (главные и побочные ступени, кадансы, период, отклонение, модуляция, органный пункт, секвенция)
8. Мелодия и фактура (мотив, фраза, кульминация, виды фактуры, регистры, голосоведение, канон)
9. Формы (период, 2- и 3-частная, рондо, вариации, сонатная форма, цикл, фуга)
10. Транспозиция и транспонирующие инструменты
11. Инструментоведение (струнные, духовые, ударные, клавишные, состав оркестра, голоса)
12. Терминология (итальянские темпы, динамика, характер, артикуляция, сокращения, орнаментика)

### Разделы сольфеджио (63 темы)

Интонационные упражнения · гаммы мажор и минор трёх видов · ступени и попевки ·
интервалы (пение и слух) · аккорды (пение и слух) · ритм (чтение, диктант, канон) ·
слуховой анализ · чтение с листа · двухголосие и музыкальный диктант.

### Музлитература (244 карточки, 87 тем)

Эпохи от Средневековья и Возрождения до XX века, зарубежная и русская музыка,
жанры (опера, балет, симфония, соната, концерт, квартет, прелюдия, фуга, этюд, романс).
Только общеизвестные проверяемые факты: Бах — барокко, Моцарт и Бетховен — классицизм,
Чайковский — романтизм, Прокофьев и Шостакович — XX век; «Щелкунчик» — Чайковский,
«Кармен» — Бизе, «Борис Годунов» — Мусоргский. Даты жизни не выдумываются: в карточках
указаны только страна и годы, проверенные по справочной традиции.

## Экран выбора инструмента

Показывается при первом запуске, доступен из настроек. Выбор влияет на визуализацию
**во всех** упражнениях:

| Инструмент | Визуализация | Подсказка |
|---|---|---|
| Фортепиано | клавиатура 2 октавы (C4–B5) | тап по клавише |
| Гитара | гриф 6 струн × 12 ладов, строй E2 A2 D3 G3 B3 E4 | «интервал = N ладов», позиция струна+лад |
| Скрипка | 4 струны G3 D4 A4 E5, позиции 0–12 полутонов | струна и позиция |
| Вокал | нотоносец + лестница ступеней I–VII | выбор ноты кнопками |
| Универсальный | только нотоносец | выбор ноты кнопками |

## Экраны

1. **Занятия** — уровень, XP, серия дней, «сегодня N из 20», умная очередь, разделы курса
2. **Библиотека** — дерево «курс → раздел → тема», конспект темы и кнопка «Тренировать эту тему»
3. **Упражнение** — 8 типов заданий, мгновенная обратная связь, звук, XP, mastery
4. **Прослушать автора** — список композиторов, карточка (годы, эпоха, стиль, темы),
   кнопки ▶ на каждую тему и «▶ все темы подряд», выбор тембра (фортепиано/струнные/щипковый)
5. **Угадай мелодию** — фрагмент 4 или 8 тактов, 4 варианта, два режима (композитор / произведение);
   после ответа — название, автор, «послушать ещё раз», «в карточку композитора»
6. **Прогресс** — график XP за 14 дней (Canvas), mastery по каждой теме, даты повторения
7. **Настройки** — инструмент, звук, сведения о приложении

## Упражнения (8 типов)

`FIND_NOTE` найди ноту · `EAR_INTERVAL` интервал на слух · `VISUAL_INTERVAL` интервал по нотам ·
`CHORD_EAR` аккорд (звук + аппликатура/клавиши/ноты) · `KEY_SIGNS` тональность и ключевые знаки ·
`RHYTHM` ритм с метрономом (допуск ±120 мс) · `LITERATURE` карточки · `LISTEN` угадай мелодию.

Генераторы покрывают всё пространство параметров: все **30** тональностей (15 мажорных и
15 минорных), все **21** интервал (14 простых + составные) вверх и вниз, все обращения и виды
аккордов (4 трезвучия + 7 септаккордов, включая D7/D65/D43/D2, SII7, VII7, умVII7), все
**8** размеров из списка. Генерация детерминирована по seed — это закреплено тестом.

## Темы: формат и правовой статус

```json
{ "id": "beethoven-elise", "composer": "Бетховен", "composerYears": "1770–1827",
  "work": "«К Элизе», главная тема", "epoch": "Классицизм", "publicDomain": true,
  "source": "нотная транскрипция главной темы (модель, не запись)",
  "notes": [ { "midi": 76, "beats": 0.5 }, { "midi": 75, "beats": 0.5 } ] }
```

**Почему только общественное достояние.** В приложении нет ни одной фонограммы: каждая тема —
это последовательность MIDI-номеров и длительностей, которую синтезатор строит на устройстве
в момент нажатия «▶». Это исполнение-модель, а не запись, поэтому авторские права на
исполнение не затрагиваются. Чтобы не возникало вопросов и с самими произведениями, в
`themes.json` включены только сочинения композиторов, умерших до 1955 года (Бах, Гайдн,
Моцарт, Бетховен, Шуберт, Шопен, Григ, Брамс, Дворжак, Глинка, Чайковский,
Римский-Корсаков, Бизе, Вагнер, Мендельсон, Сен-Санс, Гендель, Вивальди, Штраус, Равель,
Дебюсси). Современная музыка, эстрада, рок и саундтреки XX–XXI века не используются.
Тест `ThemesIntegrityTest` падает, если появится тема с `publicDomain != true` или с
композитором, умершим в 1955 году или позже.

## Шкала знаний

- **XP**: +10 за верный ответ, ×1,5 (15 XP) при серии из трёх и более верных, 0 за ошибку
- **Уровни 1–20**: порог следующего уровня = 100 × уровень, накопительно
  (`100·(L−1)·L/2`: уровень 2 — 100 XP, 3 — 300 XP, 20 — 19 000 XP), кольцо и полоса прогресса
- **Mastery темы**: доля верных за последние 10 попыток, знаменатель не меньше 10
- **Повторение**: 1 → 3 → 7 → 14 → 30 дней, ошибка сбрасывает на 1 день; сначала в очередь
  попадают просроченные и слабые темы
- **Серия дней** и счётчик «сегодня N из 20»; график XP за 14 дней
- Прогресс ведётся **по каждой теме** (270 тем в базе), а не только по курсу

## Тесты (JVM)

`TheoryTest`, `ProgressTest` — ноты, интервалы, тональности, аккорды, гриф, XP/уровни, SRS,
mastery, ритм, JSON-парсер.
`ContentCoverageTest` — **падает**, если разделов/тем/карточек меньше требуемого, если нет
композитора, эпохи, жанра, тональности, интервала, аккорда или размера.
`ThemesIntegrityTest` — структура тем, PD-статус (смерть < 1955), безопасность пустого списка.
`QuizGenerationTest` — детерминированность, покрытие 30 тональностей / 21 интервала / 11 аккордов /
8 размеров, корректность вариантов ответа.

## Ограничения

- Приложение **не тестировалось на реальном устройстве или эмуляторе** — проверены сборка и JVM-тесты
- Мелодии тем — короткие мотивные модели, транскрибированные по памяти; перед публикацией их
  стоит сверить с партитурами (структура и PD-статус проверяются тестом, точность нот — нет)
- Звук синтезируется (синусоида с гармониками), тембр условный; при отсутствии аудиовыхода
  звук молча пропускается
- Нотоносец упрощён (свой росчерк вместо глифа ключа); для вокала и универсального инструмента
  ответ выбирается кнопками нот
- Интервалы называются по полутоновой таблице (м2…ч8, составные), без энгармонических уточнений
- Тёмная тема единственная, локализация только русская

## Сверка с учебником

Разделы теории сверены с учебником В. А. Вахромеева «Элементарная теория музыки» (24 главы).
По итогам сверки добавлены темы, которых не хватало: гармонический мажор, мелодический мажор,
родство тональностей и хроматизм, определение тональности, мелизмы (форшлаг, мордент, трель,
группетто) и знаки приёмов исполнения — всего 126 тем теории.

Текст учебника использован только как справочник для проверки фактов: в приложении — собственные
формулировки, сам текст книги в репозиторий и в APK не попадает.
