# Теория — тренажёр сольфеджио, теории музыки и музлитературы

Android-приложение на Kotlin + Jetpack Compose (Material 3), полностью офлайн.
Собрано и протестировано в GitHub Actions; готовый debug APK лежит в артефактах workflow
`teoria-debug-apk`.

- minSdk 26, target/compileSdk 35, Kotlin 1.9.24, Compose BOM 2024.09.03, AGP 8.7.2, Gradle 8.9
- Room (topics / attempts / srs / profile), Navigation-Compose, SharedPreferences для выбора инструмента
- Разрешения: только `POST_NOTIFICATIONS` (объявлено; уведомления не отправляются). Сеть не используется
- Звук синтезируется на устройстве через `AudioTrack` (синусоида с огибающей), внешних аудиофайлов нет

## Экран выбора инструмента

Показывается при первом запуске, доступен из настроек. Выбор сохраняется в SharedPreferences и в
таблице `profile` и влияет на визуализацию **во всех** упражнениях:

| Инструмент | Что показывается | Подсказка |
|---|---|---|
| Фортепиано | клавиатура 2 октавы (C4–B5), белые/чёрные клавиши | тап по клавише |
| Гитара | гриф 6 струн × 12 ладов, строй E2 A2 D3 G3 B3 E4 | «интервал = N ладов», позиции струна+лад |
| Скрипка | 4 струны G3 D4 A4 E5, позиции 0–12 полутонов | строка/позиция |
| Вокал | нотоносец + лестница ступеней I–VII | выбор ноты кнопками |
| Универсальный | только нотоносец | выбор ноты кнопками |

## Курсы и темы (12 тем, 3–4 на курс, 7 типов упражнений)

**Сольфеджио**
1. Ноты и октавы — «Найди ноту»: тап по клавише/ладу/струне или выбор ноты на нотоносце
2. Интервалы на слух — синтезируются две ноты, 4 варианта ответа
3. Интервалы по нотам — две ноты на нотоносце, 4 варианта
4. Ритм и метроном — 4 клика метронома, тапы по большой кнопке с допуском ±120 мс

**Теория**
5. Диезные тональности — сколько знаков / какая тональность (G D A E B F# C#)
6. Бемольные тональности — обратный порядок (F Bb Eb Ab Db Gb Cb)
7. Аккорды — на слух: мажор / минор / уменьшённый / увеличенный; после ответа показывается
   аппликатура на грифе, подсветка клавиш или ноты на нотоносце
8. Ступени и лад — поиск ноты по ступени в выбранном инструменте

**Музлитература** (50 карточек: композитор ↔ эпоха ↔ произведение)
9. Композитор и эпоха
10. Опера и балет
11. Композитор и произведение
12. Русская и советская музыка

Упражнения с мгновенной обратной связью: верно/неверно, правильный ответ, XP, звук.

## Точность музыкального контента

- Порядок диезов: фа, до, соль, ре, ля, ми, си; бемолей — обратный
- Диезные тональности: G(1) D(2) A(3) E(4) B(5) F#(6) C#(7); бемольные: F(1) Bb(2) Eb(3) Ab(4) Db(5) Gb(6) Cb(7)
- Интервалы: м2=1, б2=2, м3=3, б3=4, ч4=5, тритон=6, ч5=7, м6=8, б6=9, м7=10, б7=11, ч8=12 полутонов
- Аккорды: мажор 0-4-7, минор 0-3-7, уменьшённый 0-3-6, увеличенный 0-4-8
- Все примеры интервалов проверяются тестом: полутоны пары нот совпадают с таблицей
- Музлитература — только общеизвестные факты, без вымышленных дат: Бах — барокко,
  Моцарт и Бетховен — классицизм, Чайковский — романтизм, Прокофьев и Шостакович — XX век;
  «Щелкунчик» — Чайковский, «Кармен» — Бизе, «Борис Годунов» — Мусоргский

## Шкала знаний

- **XP**: +10 за верный ответ; при серии из трёх и более верных подряд — ×1,5 (15 XP); за ошибку 0
- **Уровни 1–20**: порог следующего уровня = 100 × уровень, накопительно
  (`xpForLevelStart(L) = 100·(L−1)·L/2`, уровень 2 — 100 XP, уровень 3 — 300 XP, уровень 20 — 19 000 XP).
  Прогресс-бар и кольцо текущего уровня
- **Mastery темы**: доля верных за последние 10 попыток; знаменатель не меньше 10, поэтому
  три верных ответа дают 30 %, а не 100 %. Показывается кольцом и полосой
- **Интервальное повторение**: 1 → 3 → 7 → 14 → 30 дней, ошибка сбрасывает интервал на 1 день.
  В «умную очередь» первыми попадают просроченные темы и темы с низким mastery
  (`priority = 10·просрочено + 2·дней_просрочки + 3·(1−mastery)`)
- **Серия дней** (streak) и счётчик «сегодня N из 20»
- **Экран «Прогресс»**: график XP за 14 дней (Compose Canvas), mastery по всем темам, даты повторения

## Архитектура

```
app/src/main/java/ru/teoria/lab/
├── core/        чистый Kotlin без Android: ноты, интервалы, тональности, аккорды,
│                гриф/струны, уровни, SRS, ритм, генератор заданий, база музлитературы
├── data/        Room (entities, DAO, database), репозиторий, SharedPreferences
├── audio/       Synth — AudioTrack, синусоида с огибающей, метроном
├── ui/          Compose: экраны, ViewModel, компоненты (клавиатура, гриф, нотоносец, лестница)
└── MainActivity.kt
```

Генерация упражнений детерминирована по seed: `QuizGenerator.generate(topic, seed, instrument)`.
Один и тот же seed даёт одно и то же задание — это проверяется юнит-тестом.

Юнит-тесты (JVM, 30 методов в 3 классах): уровни/XP, SRS-интервалы, mastery, интервалы по
полутонам, ключевые знаки для 14 тональностей, аккорды, формат нот (до-диез / ре-бемоль),
допуск тапов ритма, строй и позиции гитары/скрипки, детерминированность генератора, база
музлитературы, структура курсов.

## CI

`.github/workflows/android.yml`: JDK 17 → `gradle/actions/setup-gradle@v4` (Gradle 8.9, без wrapper) →
`gradle :app:testDebugUnitTest` → `gradle :app:assembleDebug` → артефакты `teoria-debug-apk` и
`teoria-unit-test-report`.

## Ограничения

- Приложение **не тестировалось на реальном устройстве или эмуляторе** — проверена только
  сборка и JVM-тесты логики в CI
- Звук синтезируется приложением (синусоида), тембр не «рояльный»; на устройствах без
  аудиовыхода звук молча пропускается и не ломает упражнение
- База музлитературы — только общеизвестные факты, 50 карточек; даты жизни композиторов
  намеренно не приводятся
- Точность тапов метронома зависит от аудиозадержки устройства (±120 мс — программный допуск)
- Нотоносец рисуется упрощённо (свой росчерк вместо глифа скрипичного ключа); для вокала и
  универсального инструмента ответ выбирается кнопками нот, а не тапом по нотоносцу
- Интервалы называются по полутоновой таблице (м2…ч8, тритон), без энгармонических уточнений
- Тёмная тема — единственная; локализация только русская
